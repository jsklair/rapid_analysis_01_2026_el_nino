# Rapid Analysis 01: The Developing 2026 El Niño in Historical Context

A short, topical analysis placing the developing 2026 El Niño in the context of previous major events using NOAA Relative Oceanic Niño Index (RONI) data.

## Analytical question

**How exceptional is the developing 2026 El Niño compared with previous major events at the same stage of their evolution?**

## Status

Analysis in progress.

The project uses historical NOAA RONI observations and the current NOAA forecast outlook, with observed and forecast values treated separately.

## Scope

The analysis focuses on:

- the JJA 2026 RONI value relative to previous strong or very strong El Niño episodes;
- the pace of development from MAM to JJA;
- how previous major events evolved into the following winter;
- how NOAA's current forecast compares with the historical observed range.

Regional weather impacts are outside scope.
